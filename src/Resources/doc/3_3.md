### 3.3 Get validation groups from a closure

If validation groups are defined as a PHP callback, the bundle cannot execute
the same decision logic in the browser. You need to provide the equivalent
logic on the JavaScript side.

```php
<?php

namespace App\Form;

use App\Entity\User;
use Symfony\Component\Form\AbstractType;
use Symfony\Component\Form\FormInterface;
use Symfony\Component\OptionsResolver\OptionsResolver;

class UserType extends AbstractType
{
    public function configureOptions(OptionsResolver $resolver): void
    {
        $resolver->setDefaults([
            'data_class' => User::class,
            'validation_groups' => function (FormInterface $form): array {
                if (...) {
                    return ['Default', 'registration'];
                }

                return ['Default'];
            },
        ]);
    }
}
```

Implement the same group selection for the form validator:

```js
$('form#user').jsFormValidator({
    groups: function () {
        if (...) {
            return ['Default', 'registration'];
        }

        return ['Default'];
    }
});
```

Pure JavaScript:

```js
var field = document.getElementById('user');
FpJsFormValidator.customize(field, {
    groups: function () {
        if (...) {
            return ['Default', 'registration'];
        }

        return ['Default'];
    }
});
```
