### 2.2 Forms in sub-requests

The JavaScript initializer only knows about forms that were queued before
`init_js_validation()` is rendered.

If your form is rendered in a sub-request, for example:

```twig
<div id="email">
    {{ render(controller('App\\Controller\\EmailController::sendEmail')) }}
</div>
```

the initializer in the parent template may not know about that form. Render the
initializer in the sub-template that renders the form:

```twig
{# templates/email/send_email.html.twig #}

{{ form(form) }}
{{ init_js_validation(form) }}
```
